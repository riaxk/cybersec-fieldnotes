# Day 001 - Linux Fundamentals

Platform: TryHackMe

## Objective
- To understand what is Linux
- Learn navigating through files using Terminal
- Basic Linux commands
- Shell operators

## What I Learned
- Linux is an open source, lightweight operating system, it has subversions like Debian, ubuntu. It was created in 1991 by Linus Torvald.
- Terminal is used for file navigation using various commands.
- Shell operators are used along with the commands to make everything easier or with extra features.

## Commands I Practiced
- echo: echo Hello gives output as "Hello" 
- whoami: host name
- ls: lists files
- cd: change directory
- pwd: print working directory
- cat: concatenate, to read contents of a .txt file
- find: to find a file
- grep: to find some specific content from a file
eg. grep "Hello" greetings.txt
- wc: to list number of entries in a file

## Shell Operators
- &: to perform a process in the background
- &&: to combine multiple commands together
- >: to echo something directly to a file
- >>: to echo something to a file without overwriting
...
