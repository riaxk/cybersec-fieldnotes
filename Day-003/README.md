## Important Commands

- nano: used to create or edit file with inbuilt shortcuts
- VIM: used to create or edit file in a better way with customizable shortcuts
- wget: it is used to download a file directly from the browser url
- ps: used to list ongoing processes
- kill: used to kill a process
- systemctl: this command allows to interact with the systemd managing processes

---

## Key Takeaways

- cron processes are the ones that are scheduled for eg. when a process is supposed to start at rebooting that can be set through crontabs
- crontabs uses MIN, HOUR, DOM, MON, DOW, CMD 
- apt repository is like the root repo to upload software 
- more repos can be made using add-apt-repository
- /var/log contains all the details of user activity
